# ハノイの塔・探索デモ

ランダムに配置した4枚の円盤を右の柱へ集める状態空間を、BFSとDFSで探索する自動デモです。簡単すぎる初期配置は除外し、BFSとDFSは同じ初期配置で比較します。両方が終わると次の初期配置をランダムに選びます。

- 左側に現在探索している塔を表示
- 右側に左から右へ伸びる探索ツリーを表示し、カメラが現在地へ緩やかに追従
- BFSとDFSを同じ初期状態で交互に自動再生
- 赤から白の連続色で探索候補の順番を表示
- 探索済み、現在地、正解経路を色分け
- ゴール後はボタンで正解経路を再生可能。操作がなければカウントダウン後に自動で次へ進行
- 速度調整と手動のアルゴリズム切り替えに対応

`index.html` をブラウザで開けば動作します。将来の統合用として、`window.hanoiDemo` に `start()`、`stop()`、`reset()`、`setAlgorithm()` を公開しています。
