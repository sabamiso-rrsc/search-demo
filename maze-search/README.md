# 迷路探索ラボ

幅優先探索（BFS）と深さ優先探索（DFS）が同じ迷路を探索する様子を自動で比較する、外部依存なしのブラウザデモです。

## 起動

`index.html` をブラウザで開いてください。ローカルサーバーを使う場合は、このフォルダーで次のように起動できます。

```powershell
python -m http.server 8000
```

その後、`http://localhost:8000` を開きます。

## 自動再生

ページを開くと、次の順序で自動再生を繰り返します。

1. BFSで迷路を探索
2. 同じ迷路をDFSで探索
3. 新しい迷路を生成
4. BFSへ戻る

操作として残しているのは次の3種類です。

- **BFS / DFS**: 押したアルゴリズムで、現在の迷路を最初から探索します。
- **探索スピード**: 自動再生の速度を変更します。
- **新しい迷路にする**: 迷路を生成し直し、BFSから自動再生します。

キュー／スタックは座標ではなく赤から白への連続色で表示します。赤い候補ほど先に探索し、白い候補ほどあとで探索します。迷路上の候補も同じ色になります。

## 同時比較版

`compare.html` は、同じ迷路をBFSとDFSが左右で同時に探索します。両方の探索が完了すると、自動的に新しい迷路へ進みます。操作は速度変更と新しい迷路の生成だけです。
