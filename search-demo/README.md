# 探索アルゴリズム統合デモ

`index.html` を開くと、迷路とハノイの塔を上部のボタンで切り替えられます。

- 迷路は同じ盤面をBFS・DFSが左右同時に探索します。
- 自動切替は初期状態でON。迷路の両探索と結果表示が終わるとハノイへ、ハノイのBFS・DFSと結果表示が終わると迷路へ進みます。
- 自動切替をOFFにすると、選択したデモだけを繰り返します。
- ハノイの解答経路を再生した場合、再生終了後のカウントダウンまで待ちます。初期状態の1.5秒待機も維持しています。
- 手動切替はいつでも可能。選んだデモは最初から始まり、デモごとの速度設定は画面を開いている間保持します。
- `#maze` / `#hanoi` で最初に表示するデモを指定できます。

既存の `maze-search/compare.html` と `hanoi-search/index.html` を読み込むため、3つのフォルダーを同じ階層に置いてください。既存ページは単独でも利用できます。インターネット接続や外部ライブラリーは不要です。

ローカルサーバーで開く場合は、`demos` フォルダーで `node search-demo/serve.cjs` を実行し、`http://127.0.0.1:8765/search-demo/` を開きます。
